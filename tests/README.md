# Testing and Verification

This project has been verified using manual console testing and Java test runner classes.

## Available Test Runners

The following test classes are located in `src/com/estatehub/main/`:

- DatabaseConnectionTest.java: Checks the MySQL database connection.
- PropertyModuleTest.java: Used for property module verification.
- CSVImportTest.java: Used for CSV property import verification.

## Manual Testing

The application modules should be tested through the main CLI menu.

Areas verified include:
- Property management operations.
- Property search, filtering, and sorting.
- EMI calculator.
- User registration and profile management.
- Customer inquiries and tour requests.
- Admin property approval and dashboard.
- Inquiry reports and CSV export.
- Database connectivity and persistence.
- Concurrency demonstrations.

This directory currently contains documentation only. No automated testing framework or test suite is included.
