# Tests Directory

This directory contains test suites, validation runners, and verification scripts for the project:

- Milestone 1: OOP encapsulation, string formatting, and exception handling tests.
- Milestone 2: Collection operations, search/filter algorithms, and sorting comparator tests.
- Milestone 3: Multithreading race condition and synchronization validation.
- Milestone 4: Producer-consumer queue throughput and executor lifecycle tests.
- Milestone 5: JDBC CRUD and transactional integrity tests.
